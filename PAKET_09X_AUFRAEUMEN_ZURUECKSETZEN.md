# Paket 9x – Wochenplan aufräumen + Zurücksetzen

Behoben:

## Wochenplan
- Die Kinder-/Gruppenauswahl im Editor wurde vollständig entfernt.
- Die Zielgruppe wird nur noch vor dem Öffnen des Plans gewählt.
- Im Editor steht lediglich eine ruhige Zusammenfassung:
  „Ganze Klasse“ bzw. „X ausgewählte Kinder“.
- Die gespeicherte Zielgruppe bleibt beim Bearbeiten erhalten.

## Trainingszeit
- Neuer Bereich „Trainingszeit zurücksetzen für …“.
- Ein Kind auswählen → alle bereits bearbeiteten Trainingsaufgaben dieses Kindes
  werden nach Bestätigung wieder auf „offen“ gesetzt.
- Einzelne Aufgaben können weiterhin wie bisher separat zurückgesetzt werden.

## Lernspiele
- Neuer Bereich „Ergebnisse zurücksetzen“.
- Kind auswählen → Zurücksetzen gilt nur für das gerade ausgewählte Lernspiel.
- Frühere Ergebnisse und Aktivitätsmeldungen werden aus der Auswertung ausgeblendet.
- Die Reset-Information wird als aktualisierter Datensatz gespeichert, damit sie
  durch den Kinder-Sync nicht einfach wieder zurückkommt.

## Druckfenster
- Klick neben das Druckfenster schließt es.
- Esc schließt es ebenfalls.
- Abbrechen und X bleiben erhalten.
- Die bereits im Wochenplan festgelegte Kinder-Zielgruppe wird weiterhin automatisch übernommen.

Enthält auch alle noch nicht hochgeladenen Änderungen aus 9u–9w.
