# Paket 10a – untere Wochenplan-Felder beschreibbar

Im Druckdialog gibt es jetzt drei optionale Eingabefelder:
- Daran denke ich
- Mitteilung Lehrkraft
- Mitteilung Eltern

Verhalten:
- eingegebener Text wird im entsprechenden unteren Kasten gedruckt
- bleibt ein Eingabefeld leer, erscheinen dort weiterhin die bisherigen Schreiblinien
- mehrzeilige Eingaben werden mehrzeilig gedruckt
- bei mehreren Ausdrucken gilt der eingetragene Text für alle in diesem Druckvorgang erzeugten Pläne

Enthält Paket 9z und damit auch die vorherigen Druck-/Wochenfensterkorrekturen.
