# Paket 9s – Mehrere Wochenpläne pro Kalenderwoche

Neu:
- Im Wochenfenster ist immer „+ Weiteren Wochenplan anlegen“ möglich.
- Vor dem Editor wird ausgewählt: ganze Klasse, vorhandene Gruppe oder einzelne Kinder.
- Titelvorschläge:
  - Ganze Klasse → „Klasse“
  - Gruppe → Gruppenname
  - ein Kind → „Einzelplan – …“
  - mehrere ausgewählte Kinder → „Auswahl – X Kinder“
- Der Titel bleibt im Editor frei änderbar.
- Jede Plan-Karte zeigt sichtbar, für wen der Plan gilt.
- Bei mehreren Plänen öffnet „Plan bearbeiten“ nicht mehr willkürlich den ersten Plan; die einzelnen Karten sind die Auswahl.
- Paket 9r (Wochenfenster) und Paket 9q (Kinder-Sync-Fix) sind enthalten.
