# Schritt 3i – Seitenstatus und Heftreihenfolge

- Beim Zurücksetzen einer fertig markierten Seite wird die Klassenübersicht aus dem aktuellen Datenstand neu gerendert. Eine wieder offene Seite erscheint im aktiven Plan erneut oben; historisch erfasste Seiten bleiben als Status sichtbar.
- Eine neuere explizite Statusänderung hat Vorrang vor einem älteren „fertig“-Datensatz.
- Die Heftteile von MiniMax werden A, B, Größen und Sachrechnen, Geometrie, Teste dich sortiert.
- Der Wochentags-Badge wird nur im Seiten-Auswahldialog nicht mehr angezeigt. Die gespeicherte Tageszuordnung bleibt erhalten.

## Lokal starten
1. Im bisherigen Terminal Ctrl+C drücken.
2. ZIP entpacken und den neuen Ordner öffnen.
3. `start-local.command` doppelklicken, Terminal offen lassen.
4. `http://localhost:8770` in Chrome öffnen und bei Bedarf Cmd+Shift+R drücken.
5. Zum Beenden Terminal Ctrl+C.
