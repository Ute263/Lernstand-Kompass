# Schritt 3m – Kinderaufgaben und individuelle Pläne

- Statusänderung bei Pflichtaufgaben wird **vor** optionaler Lernstandsübernahme gespeichert.
- Fehler bei automatischer Lernstandsübernahme lassen das Häkchen nicht wieder verschwinden.
- Klassenplan und individuelle, zeitlich überlappende Pläne erscheinen in der Kinderansicht separat und können beide bearbeitet werden.
- Bestehende Speicherformate, Druckvorlagen und Kinder-Tier-IDs bleiben erhalten.

## Start

1. Alten localhost-Server im Terminal mit Control + C stoppen; Terminal schließen.
2. ZIP separat entpacken, `start-local.command` im Ordner doppelklicken.
3. Terminal offen lassen; `http://localhost:8770` in Chrome öffnen.
4. Wenn eine alte Version erscheint: Command + Shift + R. Website-Daten keinesfalls löschen.
5. Beenden: Control + C im Terminal.
