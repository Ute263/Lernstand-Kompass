# Schritt 3d – Wochenplan neu geordnet

Die bestehende Original-App bleibt funktionsfaehige Grundlage. Nur die sichtbare Lehrer-Wochenplanmaske wurde neu gegliedert. Die Speicher- und Drucklogik sowie der Kinderbereich bleiben unveraendert.

## Start (Mac)
1. Bisheriges Terminal: **Control+C** druecken, dann Fenster schliessen.
2. ZIP entpacken (nicht im GitHub-Ordner).
3. Im Ordner `Lernstand-Kompass-Original-Schritt3d` die `start-local.command` doppelklicken (ggf. Rechtsklick > Oeffnen).
4. Terminal offen lassen. In Chrome `http://localhost:8770` aufrufen.
5. Falls noch die alte Ansicht zu sehen ist: **Command+Shift+R**. Keine Website-Daten loeschen.
6. Nach dem Test im Terminal wieder **Control+C**.

Bitte vor Tests mit eigenen Daten ein Backup exportieren. Github und Cloudflare bleiben unveraendert.
