# Schritt 3h: Start und Änderungen

- Deutsch und Mathe gleich groß, untereinander, jeweils nur eines aufgeklappt.
- Unterpunkte bei Deutsch kleiner und leichter.
- Für alle Klassen 1 bis 4: Themen des Inhaltsverzeichnisses statt starrer 20-Seiten-Blöcke, sofern im Katalog erfasst. Jede Seite einzeln anklickbar.
- Original-Datenhaltung und Druck unverändert.

## Mac-Start
1. Im alten Terminal Control+C drücken und schließen.
2. ZIP entpacken, Ordner Lernstand-Kompass-Original-Schritt3h öffnen.
3. start-local.command doppelklicken und Terminal geöffnet lassen.
4. http://localhost:8770 in Chrome öffnen; ggf. Cmd+Shift+R.
5. Zum Beenden im Terminal Control+C drücken.

Die lokale App ist eine Testversion. Vor dem Wechsel ein Backup erstellen. GitHub und Cloudflare nicht ändern.
