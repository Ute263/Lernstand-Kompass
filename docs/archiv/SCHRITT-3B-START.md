# Lernstand-Kompass – Schritt 3b: Leichtes Lehrerlayout

**Änderungen:** Lehrer-Navigation schmaler und ohne Kartenhintergrund; reduzierte Schriftgewichte und Überschriften; weiße Flächen, weniger Schatten, kleinere Schaltflächen. Startbildschirm ebenfalls kompakter. Die vorhandenen Funktionen, Kinderansicht, Druckansichten und Speicherformate bleiben erhalten.

**Lokal starten:** Vorigen Server im Terminal mit **Control+C** beenden. Neuen ZIP-Ordner entpacken und `start-local.command` doppelklicken. Terminal geöffnet lassen. In Chrome `http://localhost:8770` aufrufen. Bei alter Darstellung **Command+Shift+R**. Zum Beenden im Terminal **Control+C**.

**Hinweis:** Keine neue Navigationslogik eingeführt; alle bestehenden Menügruppen bleiben erreichbar. Optische Änderung im Lehrerbereich, keine Funktionsmigration. Manrope ist als bevorzugte Schrift angegeben; falls sie auf dem Gerät nicht vorhanden ist, verwendet die App Avenir Next bzw. eine Systemschrift.
