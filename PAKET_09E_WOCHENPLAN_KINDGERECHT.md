# Paket 9e – Wochenplan kindgerecht + freie Aufgaben + Stern + Rico Schnabel 2

Enthält Paket 9d vollständig.

## ⭐ Stern jederzeit möglich
Jede einzelne Wochenplan-Aufgabe hat im Editor einen Stern-Schalter:
- ☆ normale Aufgabe
- ⭐ Zusatzaufgabe

Das gilt für Heftseiten und freie Aufgaben. Eine doppelt gewählte Heftseite wird weiterhin zunächst automatisch als Zusatzaufgabe vorgeschlagen; der Stern kann aber jederzeit wieder entfernt werden.

## ✏️ Freie Aufgaben ohne Heft
Für jeden Tag gibt es freie Aufgaben direkt unter:
- Deutsch
- Mathe
- Sonstiges

Es können mehrere freie Aufgaben ergänzt werden. Jede freie Aufgabe kann ebenfalls mit ⭐ markiert und einzeln gelöscht werden.

## 📘 Rico Schnabel 2 – Rechtschreiben
Für eine aktive Klasse 2 wird das Heft automatisch ergänzt:
- Deutsch
- Klasse 2
- Seiten 4–112
- Themen aus dem vom Nutzer bereitgestellten Inhaltsverzeichnis

Im Heft-Bereich gibt es außerdem einen eigenen Rico-Schnabel-Button, falls das Heft manuell ergänzt werden soll.

## 👧 Kindgerechte Wochenansicht
Die bisherige breite 5-Spalten-Ansicht wurde ersetzt:
- immer nur EIN Wochentag gleichzeitig
- Mo / Di / Mi / Do / Fr als große Tages-Tabs
- keine horizontal verzogene Wochenübersicht mehr
- Aufgaben als einzelne große Karten
- Deutsch 📘, Mathe 🔢 und freie Aufgabe ✏️ klar erkennbar
- ⭐ Zusatzaufgabe sichtbar, aber nicht dominant
- Status: Offen / Angefangen / Fertig
- Buttons: „Ich bin dran“ und „Fertig ✓“
- auf Handy/iPad vollständig responsive
- bei mehreren Wochenplänen wird nur ein Plan gleichzeitig angezeigt

## Weniger Scrollen in der Lehrkraftansicht
Die fünf Tage sind im Editor als aufklappbare Tageskarten aufgebaut. So ist nicht mehr der komplette Wochenplan gleichzeitig offen.
