# Paket 9r – Wochenplanung im Fenster

- Klick auf eine Kalenderwoche öffnet die Wochenplanung als großes Fenster über dem Kalender.
- Der Detailbereich wird nicht mehr unter den Monaten angehängt.
- Schließen mit ×, Klick neben das Fenster oder Escape.
- Plan erstellen/bearbeiten funktioniert weiterhin wie bisher.
- Paket 9q (Kinder-Sync-Fix) ist in diesem Paket mit enthalten.
