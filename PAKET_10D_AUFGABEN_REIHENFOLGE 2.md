# Paket 10d – Aufgabenreihenfolge ändern

Neu:
- Jede ausgewählte Heftaufgabe hat ↑ / ↓.
- Auch freie Aufgaben haben ↑ / ↓.
- Die Reihenfolge wird im Wochenplan-Draft gespeichert und beim Speichern übernommen.
- Kinderansicht und Ausdruck verwenden dieselbe Reihenfolge.

Wochenmodus:
- Pflichtaufgaben bleiben grundsätzlich vor Sternchenaufgaben.
- Innerhalb der Pflichtaufgaben frei sortierbar.
- Innerhalb der Sternchenaufgaben frei sortierbar.
- ↑ / ↓ überspringt automatisch Aufgaben der jeweils anderen Gruppe.

Tagesmodus:
- Aufgaben können innerhalb des jeweiligen Fach-/Aufgabenblocks frei nach oben/unten verschoben werden.

Baut auf Paket 10c auf.
