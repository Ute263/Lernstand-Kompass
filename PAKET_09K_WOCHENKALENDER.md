# Paket 9k – Wochenübersicht als Schuljahreskalender

Im Wochenplan gibt es nur noch:
- 📅 Wochenübersicht
- ✏️ Plan bearbeiten
- 📚 Hefte

Der eigene Bereich „Vorlagen“ und die Bezeichnung „Diese Woche“ entfallen.

Die Wochenübersicht zeigt das Schuljahr August bis Juli nach Kalenderwochen:
- ✓ fertig geplant
- ◐ begonnen
- ○ offen

Klick auf eine Woche:
- vorhandener Plan → Bearbeiten, 🖨 Drucken, Kopieren
- kein Plan → + Wochenplan erstellen

Beim Erstellen werden KW und Zeitraum Montag–Freitag automatisch eingetragen.
Bereits vorhandene Pläne gelten zunächst als fertig geplant.
Neu über den Kalender erstellte Pläne stehen nach dem ersten Speichern auf „begonnen“
und können bewusst mit „✓ Als fertig geplant markieren“ abgeschlossen werden.
